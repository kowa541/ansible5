# ansible5
# Лабораторная работа П05: Сканирование сети с помощью Nmap и Ansible

## Цель работы
Использование Ansible для автоматизированной установки утилиты Nmap на целевой хост, передачи списка целей и выполнения сканирования с последующим выводом результатов.

## Инфраструктура
- **Управляющая машина (ANSIBLE1):** `10.0.2.4`
- **Целевая машина (ANSIBLE2):** `10.0.2.3`

## Структура проекта
- `inventory.ini` — файл инвентаризации.
- `targets.txt` — текстовый файл со списком целей для сканирования (включает внешние домены и локальные IP).
- `nmap_scan.yml` — плейбук для развертывания и запуска сканирования.

## Логика работы плейбука
1. Обновление кэша пакетов и установка `nmap` (с эскалацией привилегий `become: yes`).
2. Копирование файла `targets.txt` на целевую машину в `/tmp/`.
3. Выполнение команды `nmap -iL /tmp/targets.txt` с сохранением вывода в переменную через `register`.
4. Вывод результатов сканирования в консоль с помощью модуля `debug` и параметра `stdout_lines`.

## Результаты
Сканирование успешно выполнено. В выводе задачи `Show scan results` отображены открытые порты и сервисы для каждой цели из списка.
